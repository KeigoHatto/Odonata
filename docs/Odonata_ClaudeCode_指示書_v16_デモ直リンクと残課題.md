## Phase 35：「デモを見る」をデモ環境へ直リンクにする

### 背景
2026-09-20の定例で「デモを見る」から直接デモ画面へ飛ばす方針に決定。デモ環境のログイン画面は「コーチ用／選手用」をタップするだけで入れる作りになっているので、ID・パスワードの案内は不要。

デモURL：`https://odonata-demo.onrender.com/login`

### タスク
1. **デモURLを1か所で管理する**：パーシャル（ナビ・フッター）で使える定数か、共通の設定に置く。ページ本文のCTAも同じ値を参照できる形が望ましい。難しければ、置換箇所の一覧を `docs/refactor-notes.md` に残す
2. **全ページの「デモを見る」CTAのリンク先をデモURLに変更**：ナビ（グロナビ・モバイルメニュー）、Hero、ページ末CTA、フッター。`grep -rn "demo.html"` で漏れを確認する
   - 外部サービスなので `target="_blank" rel="noopener"` とし、**新しいタブで開くことを視覚的に隠したテキストで伝える**（例：`<span class="visually-hidden">（新しいタブで開きます）</span>`）。アイコンは使わない（CTAにアイコン禁止のルール）
   - CTAの文言・序列（デモを見る＝塗り＞資料請求・お問い合わせ＝枠線＞ログイン＝枠線・薄）は変えない
3. **GA4でデモのクリックを計測**：`demo_click` イベントを送る。パラメータにクリック位置（`nav` / `hero` / `cta_bottom` / `footer` / `demo_page`）を入れる
4. **`demo.html` を「画面紹介ページ」として残し、文言を更新**
   - 削除：「サンプルデータの入ったデモ環境をご用意します」「ログイン不要で操作できるデモ環境を、ご希望のチームに個別にご案内しています」「2営業日以内にご案内」「その場で操作できる公開デモ環境は準備中です」のブロック
   - 追加：ページ上部に「今すぐデモを触る」ボタン（デモURLへ）と、次の補足
     > サンプルデータの入ったデモ環境です。「コーチ用」「選手用」をタップするだけで入れます。入力したデータは定期的に初期化されます。
   - SCREEN 01〜05の画面紹介と、末尾の「自チームのデータで試したい方は。」はそのまま残す
   - `demo.html` はサイトマップに残す（削除・リダイレクトはしない）
5. **en版**：en側に同等のCTAがあれば同じ変更を入れる。デモは日本語UIなので、en版のデモ導線の近くに「The demo is in Japanese.」の一文を添える

### 検証
- `grep -rn "demo.html"` の結果が、`demo.html` 自身のcanonical・パンくず・サイトマップ・「画面紹介」導線のみになっていること
- `npm run check` が通ること、`npm run a11y` の違反件数が作業前から増えていないこと

## Phase 36：料金ページ（pricing.html）の書き直し

### 背景
金額は載せない方針（2026-09-21確認）。それに合わせて「費用の決まり方」の説明も具体的にしすぎず、やわらかくする。また、法人登記前は見積書を出さない方針なので、「書面でお見積りをご提示」の表現を外す。

### タスク
1. **表示崩れの修正**：「費用の考え方」のデータプラットフォームのカードで、チェックリストの `<li>` 内の太字部分と通常テキストが2列に割れている（「選手・スタッフのアカウント数は無制限」と「（人数による追加費用はありません）」が横に分かれる、「GPSがなくても 、日々の…」で読点の前に空白が入る）。`<li>` に当たっている `display:flex`（または grid）が原因とみられる。**テキストが1つの段落として自然に折り返す**ように直す。同じクラスを使う他ページも確認する

## Phase 37：技術的負債の解消（v15 Phase 29〜34 の消化）

### 最初にやること
`Odonata_ClaudeCode_指示書_v15_残課題の解消.md`（Phase 29〜34）がどこまで終わっているかを、`git log` と実ファイルで確認し、**未完了のものだけ**を下の順で進める。完了済みのものは報告に「完了済み（コミットID）」と書く。

### 対象（2026-09-07時点で判明していたもの）
1. **`.tbl` の横スクロールが効かない**：`site.css` の `@media` で `overflow-x:auto` を当てた後に、`.tbl{...overflow:hidden...}` が同じ詳細度で上書きしている（宣言順のバグ）。`guide.html` 独自の `.tbl`（表21個）には `@media` 自体がない
2. **ヒーローのコントラスト不足**：原因はグラデーションではなく、上に重ねた netbg canvas（`opacity:.35`、guideは `.4`）。**canvas と本文の間に `rgba(7,26,58,.35)` の暗幕を1枚入れる**（4.94:1に戻る試算）
3. **`guide.html` / `philosophy.html` が `site.css` を読まず、`:root` とリセットをインラインで複製**している。`site.css` を読むように統一する。`.wrap` の最大幅（1180px）を `--maxw:1140px` に合わせる。`philosophy.html:113` に残っている白化フィルタ（v12の積み残し）を撤去
4. **`kessan.html` の「株式会社Odonata」3箇所**（62 / 99＝コメント内テンプレート / 113）を「Odonata」に。**法人登記前は「株式会社Odonata」と書かない**
5. **検査スクリプトの誤検知**：`philosophy.html` の `gradientTextFail` 14件は、実効opacityが0のスクロール連動レイヤー（`.zlayer.lockup`）が対象。`scripts/a11y-check.mjs` 側で**実効opacity 0の要素を除外**する
6. **非標準ブレークポイント16件、`!important` 34件、未使用CSS（`.price`, `.check-list` など）**：ブレークポイントを標準値に寄せ、不要な `!important` と未使用CSSを削除。見た目が変わる変更は1コミットずつに分け、変わる箇所を報告に書く

- en版のネイティブレビュー
